# Desktop creator — matching iOS props

Fourteen bottom-grounded, Y-up, meter-scale USDZ assets corresponding to the GLBs in `Tools/HabitatEditor/assets/models/`. Stable identities and dimensions are in that editor's JSON catalog. These are new resources; existing character and complete habitat exports remain unchanged. No Xcode resource references were added.

`manifest.json` records package and GLB hashes. Rebuild and validation instructions are in `Tools/HabitatEditor/README.md`. The starter layout requires a native Swift loader before it can be used by the app.
