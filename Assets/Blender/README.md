# Editable Blender sources

`Fibu.Soft.blend` is the editable character source. Keep future habitat Blender sources in this folder with descriptive filenames. Pack external textures or include them with relative paths. Commit `.blend` sources; Blender numbered backups and autosaves are ignored.

Export separate runtime USDZ modules to `Assets/Models/`; preserve the existing `Fibu.Soft.usdz` character. Use `codex/asset-handoff` for cloud deliveries and document changes under `Assets/Handoff/`.
